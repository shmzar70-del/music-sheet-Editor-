# 🎼 Maestro Web Studio — Music Sheet Editor

A lightweight, browser-based music notation editor built with pure HTML, CSS, and JavaScript. No installation required — just open `index.html` and start composing.

## Features

- Full music notation (treble, bass, alto, tenor clefs)
- Notes, rests, dotted rhythms, and all standard durations
- Time signatures, key signatures, accidentals, and dynamics
- Automatic **guitar tablature** (TAB) for standard tuning
- **Arpeggio engine** — expands chords into written-out arpeggios color-coded by finger (p / i / m / a)
- Built-in **Web Audio playback** with piano, guitar, flute, organ, and strings
- Full **MusicXML import/export** (`.xml`, `.musicxml`, `.mxl`)
- Drag & drop note editing
- Undo / redo, zoom, and touch support
- Works offline as a **Progressive Web App (PWA)**

## Quick Start

1. Open `index.html` in any modern browser.
2. Click on the staff to add a note.
3. Press **▶** to play.

## Keyboard Shortcuts

| Key | Action |
|---|---|
| Space | Play / Stop |
| Ctrl+Z | Undo |
| Ctrl+S | Save MusicXML |
| Ctrl+O | Open file |
| T | Toggle TAB |
| A | Toggle Arpeggio |

## Install as an App

Open the site in Chrome or Safari and choose **"Add to Home Screen"**.  
An Android APK can be built with [PWABuilder](https://www.pwabuilder.com).
